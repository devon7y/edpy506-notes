Every model in this course, as something you can move

These are my notes for EDPY 506, rebuilt one topic at a time. A lecture describes what a model does; this site lets you drag the parameter and watch it happen. Nothing here goes beyond what the course covered.

How to read this

Each topic is one page, and each page is built the same way: the idea in words, then a figure you can interact with, then what the figure shows once you have played with it. The figures are not illustrations of the maths. They run the maths, in your browser, on data the page generates while you watch.

Every page uses the same example, the Edmonton home prices above, so a model on one page can be compared with a model on another without re-learning a dataset. The homes are simulated rather than real, which means the right answer is known and a page can tell you honestly when a model has found it and when it has not. The example follows the one used in class, and the figures here are built from scratch rather than adapted from the demos shown in the lectures.

Scope. Content comes from the lectures and nowhere else. Where a page shows the machinery behind a figure that the lectures did not cover, it says so and puts it in a collapsed aside, so the course material and the implementation detail never get confused with one another.
